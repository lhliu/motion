    讓 AI 直接使用這個圖鑑
    
              
    Motion Atlas 提供 MCP（Model Context Protocol）伺服器。連上之後，你只要描述需求，AI 就能查特效、組 Combo、給你預覽連結，滿意後存進 Combo 庫。
    
              
    
              
    只讀取時直接用這個網址。要讓 AI 能儲存或刪除 Combo，網址後面加上 ?key=你的金鑰，或用 Authorization: Bearer 標頭。
    
            
    
            
    
              
    
                
    Claude（網頁版／App）
    
                
    1. 設定 → 連接器 → 新增自訂連接器
    2. 名稱填 Motion Atlas，網址貼上 MCP 網址（含 ?key=）
    3. 在對話中開啟這個連接器
    
              
    
              
    
                
    Claude Code
    
                
    
              
    
              
    
                
    ChatGPT
    
                
    1. 設定 → 應用程式與連接器 → 進階設定，開啟開發者模式
    2. 建立連接器，網址貼上 MCP 網址（含 ?key=），驗證選「無」
    3. 在對話中選用這個連接器
    
              
    
              
    
                
    可以這樣說
    
                
    幫我用 Motion Atlas 做一段 Shorts 片頭，9:16、6 秒內：
先用衝擊感帶出「XX 重劃區」，再秀「步行 3 分鐘到捷運」，
最後用翻牌收在「開箱」。先給我預覽，我確認後再存成 Combo。
    
              
    
            
    
            
    提供的工具
    
            
    
              
                
    list_categories分類、情境標籤、配色讀取
    
                
    search_effects用關鍵字、分類、標籤找特效讀取
    
                
    get_effect單一特效的動態拆解、提示詞、HTML 原始碼讀取
    
                
    build_map_scene組地圖場景（基地框、路名、資訊卡、數據卡），回傳可放進 Combo 的段落讀取
    
                
    build_drop_scene組銳利水滴段落（形狀、顏色、光澤、文字位置）讀取
    
                
    compose_combo組合多段特效並產生預覽連結（不儲存）讀取
    
                
    save_combo存進 Combo 庫；帶 id 代表更新需金鑰
    
                
    list_combos / get_combo查詢 Combo 庫，當作新需求的參考讀取
    
                
    delete_combo刪除 Combo需金鑰
    
                  
            
    
            
    另有公開 API：/api/effects（特效目錄）、/api/combos（Combo 庫）、/c/<id>（Combo 全螢幕播放頁）。
