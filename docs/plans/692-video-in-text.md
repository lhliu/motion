# #692 字內實拍遮罩

## 核准範圍（2026-11-07 修訂）

KC 先核准 v2，隨後改口：**先不要包影片**。這份修訂蓋過 v2 裡「HTML 內嵌原始影片」的做法。

這次做：

- 圖片工作室新模組「字內實拍」：可選 mp4／webm／mov，或明確改放照片（靜態版）。
- 編輯時影片只用分頁暫存，不進場景、不進瀏覽器儲存。重新整理要重選。
- 預覽：影片畫進粗體字，字外實色或透明。16:9 一行，9:16 自動兩行。可調填滿／完整、焦點、推近、起始秒。
- 靜音播放。瀏覽器擋住自動播放時，顯示「點一下播放」。
- 副檔名不是編碼保證。解不開就停下並說明，不改放示意圖。
- PNG 序列：每一格先 seek，等到畫面再畫，可透明。
- WebM：沿用即時錄製，可能掉格。
- HTML：**只有目前這一格的靜態圖**，畫面上寫明沒有影片。不是播放器，沒有 base64 影片，也沒有大檔確認窗。

這次不做：把原始影片嵌進單一 HTML、離線播放器、50MB 門檻、匯出前在瀏覽器裡剪片或降解析度、逐字亮起與字外暗化（v2 的 P2）。

下面是當初的 v2 計畫，供對照。其中「HTML 內嵌影片」與「超過 50MB 要確認」已不再實作。

# #692 字內實拍遮罩 Video-in-Text Matte — 一頁計畫 v2（待 KC 核准）

**結論：做得到，HTML 匯出也會真的播影片。** 做法是把原始影片檔原封不動用 base64 嵌進單一 HTML，開檔時在瀏覽器裡還原成 blob 播放，可離線、可轉傳，不連外部檔案。網站目前還不能放影片：照片工作室只收圖片（`photo-studio.ts` 讀檔後轉 WebP dataURL，長邊 2048），全站 `src/` 沒有 `<video>`；PNG 序列（`export-kit.ts pngSequence`）是同步逐格 `draw(ctx,t)`，WebM 是 `captureStream(30)` 即時錄。要補影片素材槽、逐格 seek 匯出、HTML 內嵌播放器，MVP 估 **2～2.5 天**（v1 是 1～1.5 天）。編號 #692（目前最大 #691；#237 格局改造是另案）。

## 效果

超大粗體字當窗，窗內播客廳實拍（緩推近 1.00→1.06），字外純色或透明，可選副標；16:9 一行、9:16 自動兩行。預覽 `hero-16x9.jpg`、`hero-9x16.jpg`、`contact-sheet.jpg`，皆為**示意影片**（程序生成，非 KC 素材）。外觀與 v1 相同。

## 流程

1. 照片工作室新模組「字內實拍」，素材格選影片（mp4／webm／mov）或照片（照片＝靜態版）。
2. **編輯階段**：影片只用 `URL.createObjectURL` 暫存在本分頁，不存進場景或瀏覽器儲存（太大），重新整理要重選。
3. 框選：fit=cover／contain、x／y、縮放、起始秒 `in`。
4. 預覽：`<video muted playsinline loop>` → drawImage → `destination-in` 字形遮罩；預覽不保證逐格精準。
5. 匯出：
   - **PNG 序列（逐格精準、可透明）**：新增 async 版，每格設 `currentTime=in+i/fps`，等 `seeked` 再畫。約片長 1～3 倍時間（估）。
   - **WebM**：沿用 `recordWebm` 即時錄，可能掉格；Chrome VP9 可帶 alpha。
   - **HTML（必須能播）**：見下節。此節已由上方修訂取代：HTML 只出靜態預覽。
   - MP4：不做。

## 參數（@設定列）

`@text=這間3房; sub=新店 · 客廳實拍; font=heavy|serif; size; track; fit=cover|contain; zoom=1.06; x; y; in=0; bg=solid|none; c1=#12161E; ink; outline=0|1`

## 其他限制

- iPhone HEVC mov 在 Chrome／Windows 常解不開，建議先在剪映轉 H.264 mp4。
- 透明：剪映吃透明 WebM 不穩，透明請用 PNG 序列（同 #691）。
- 細字體窗太窄，預設粗黑體；字型載入完才可匯出。
- 影片無聲（muted），音軌在剪映處理；4K 手機上 seek 慢，建議 1080p。

## 已實測 vs 提議（v2 原文，內嵌播放器未做）

- **已實測**（計畫撰寫時的 PoC，不在 repo）：小檔 VP9 webm 與 H.264 mp4 可從 base64 還原播放。那條路這次沒有做進產品。
- **未實測**：數十 MB 大檔、Safari／iPhone／剪映內建瀏覽器、HEVC 錯誤頁、50MB 門檻。50MB 確認也沒有做。
